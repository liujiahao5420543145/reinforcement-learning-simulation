# 工程运行约定

- 默认编译并运行 `build/ball_simulate`：显示 MuJoCo 官方控制面板，同时在终端打印仿真时间和小球高度。
- 用户要求运行时，默认在系统终端软件中启动，方便查看实时数据。
- 暂停仿真时停止数据输出，继续时恢复；重置后仿真时间重新计数。
- 窗口持续运行，直到用户手动关闭，不默认在 10 秒后退出。
- 后续修改保留以上行为，除非用户明确要求更改。
- `ball_test` 简化窗口和 `--headless` 模式仅在明确需要时使用。

默认命令（在工程目录执行）：

```bash
cmake -S . -B build &&
cmake --build build -j &&
./build/ball_simulate
```
